This a global weather dashboard project that I am creating just to get some working idea of React.

If you are new to this project, consider starting from reading this design doc - [Global Weather Dashboard](https://docs.google.com/document/d/1vwlg3nGNe5d--_7FCXXEs8GIVar19lBitIt5T-8AIlg/edit?usp=sharing)

If you would like to contribute to this project, following details might help:
- I'm using Open Weather Map api free tier to make calls - https://openweathermap.org/api
- Use the "Current Weather Data" API, generate an API key by subscribing to the API, and store it in the same directory where the package.json of this project exist as a `.env` file on a variable `VITE_APP_ID="XXXXX-API-KEY-XXXXX"`
